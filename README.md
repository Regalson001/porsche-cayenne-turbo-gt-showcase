
# Porsche Cayenne Turbo GT — Dream Garage Showcase

A premium automotive wall-mount showcase inspired by the Porsche Cayenne Turbo GT.

Designed as a collector's garage display, this project combines dark-mode styling, dramatic red accents, performance specifications, interactive vehicle viewing modes and automotive-inspired typography.

## Project Preview

### Design Concept

- Matte-black collector display.
- Red performance-inspired accent lighting.
- Framed automotive poster layout.
- Large vehicle showcase.
- Technical performance specification cards.
- Black and red interior concept.
- Responsive garage-inspired interface.

## Features

- Interactive exterior and interior viewing controls.
- Animated performance statistics.
- CSS lighting and hover effects.
- Automotive specification panels.
- Responsive layouts for mobile, tablet and desktop.
- Smooth transitions and visual effects.
- Dynamic copyright year.

## Performance Specifications

The concept uses the following supplied figures:

| Specification | Value |
|---|---:|
| Engine | 4.0L Twin-Turbo V8 |

| 0–100 km/h | 3.3 seconds |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Regalson001/porsche-cayenne-turbo-gt-showcase.git
```

Open the project:

```bash
cd porsche-cayenne-turbo-gt-showcase
```

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

## Customisation

The current photographs are illustrative automotive images, not verified photographs of the exact red Porsche Cayenne Turbo GT or its black-and-red dotted seats.

For the intended collector-grade result, replace them with photographs of:

- Red Porsche Cayenne Turbo GT front exterior.
- Red Porsche Cayenne Turbo GT rear exterior.
- Black interior with red perforated seat details.
- Engine and performance details.

The images can be changed in `script.js` and in the image URLs inside `index.html` and `style.css`.
